# TaskFlow — Task Management Dashboard

## Project Overview

TaskFlow is a responsive web-based task management dashboard designed to help administrators organise tasks, monitor employee assignments, and track task progress.

## Features

- Dashboard summary cards for total, pending, completed, and overdue tasks.
- Search tasks by task title, employee name, or store.
- Filter tasks by status and store.
- Create new tasks and edit existing tasks.
- Update task status.
- Form validation for required fields.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- React
- TypeScript
- CSS
- Vite

## How to Run the Project

1. Install Node.js if it is not already installed.
2. Open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.

## Demo Data

The current version uses sample task and employee data stored in React state. Changes are temporary and reset when the application is reloaded.

## API Status

The current version does not yet connect to an external mock API. API integration and login authentication must be added if required by the supplied project specification.
